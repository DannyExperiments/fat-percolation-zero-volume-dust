# Shared-face explorer

Open `index.html` directly after extraction. Select at most one missing child in each of the adjacent four-by-four squares. The explorer reports the exact surviving seam rows. No network connection or dependencies are needed. Change the view angle with the slider or start and pause rotation. Tile thickness and spacing make the geometry easier to see.

The proof uses closed adjacent cells, so the illustrated seam is a common face. The calculation checks the first level of the shared-face induction. It does not simulate the limiting set.
